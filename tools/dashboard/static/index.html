⚠️ Comenzar un Nuevo Proyecto

Confirmación de limpieza y respaldo de seguridad.

Al iniciar un nuevo proyecto:

  • Se creará una copia de seguridad automática del proyecto actual en exports/.
  • Se limpiará el espacio de trabajo activo y los documentos anteriores para evitar mezclar requerimientos.

Se limpiará el workspace y el shared_pool para comenzar un nuevo proyecto.

Esta acción:

  • Creará un respaldo automático de la aplicación actual en exports/.
  • Limpiará environment/workspace/ y shared_pool/.
  • Restablecerá workflow_context.json a su estado base inicial.
